## How to edit the chat

- Answers live in `public/ask.json`. Jev only picks which answer fits. The
  `_readme` field in that file explains each part, including `area`.
- A new or changed answer needs its translation in every
  `tools/i18n/<lang>.mjs` under `ask.topics`, with a `src` fingerprint. Run
  the build and it prints "set its src to X" for anything out of date.
- A new general answer must name an existing area in `areas`.
- Jev's judge reads only the answer text, so an answer must state its point
  in its first sentence.
