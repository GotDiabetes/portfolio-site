## How to edit the chat

- Answers live in `public/ask.json`. Jev (TypeSafe) only picks which answer
  fits. The `_readme` field in that file explains each part.
- A new or changed answer needs its translation in every
  `tools/i18n/<lang>.mjs` under `ask.topics`. Each one has a `src`
  fingerprint. Run the build and it prints "set its src to X" for anything
  out of date.
- A new `tip_*` topic needs a `title` and a place in a `data-tips` list on
  `public/tips/index.html`.
- Jev's judge reads only the answer text, so an answer must state its point
  in its first sentence. "It's not a live chat" fixed "are you a bot?".

## Things only the local session can do

- **Deploy the Worker.** Wrangler is signed in only on Isaac's desktop.
  Deploy from `worker/` with `npx wrangler deploy --config wrangler.toml`.
- **Test the chat against a local Worker.** That needs Isaac's TypeSafe key,
  which lives only on his desktop. In the cloud, test against the live
  Worker after a push instead.
- **Bump cache keys.** Every changed CSS or JS file gets one new `?v=` key on
  every English page that loads it, then run the i18n build. The local
  helper script for this isn't in the repo, so do it by hand in the cloud.
